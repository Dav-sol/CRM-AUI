# MVP - Automatize It Platform

## Objetivo

Construir una primera versión funcional de Automatize It Platform que permita a Baterías del Caribe automatizar el seguimiento postventa de sus clientes utilizando la información exportada desde MyAsis ERP.

El objetivo del MVP es demostrar valor rápidamente mediante una solución sencilla, estable y escalable.

---

# Problema

Actualmente la empresa registra todas sus ventas en MyAsis ERP.

Sin embargo:

- No existe seguimiento automático.
- No existen recordatorios de garantía.
- No existen campañas de recompra.
- La información permanece almacenada sin generar acciones comerciales.

Como consecuencia, muchos clientes no vuelven a comprar en la empresa.

---

# Objetivo del MVP

El MVP permitirá:

- Centralizar clientes.
- Centralizar compras.
- Calcular automáticamente eventos comerciales.
- Automatizar campañas de WhatsApp.
- Registrar conversaciones.
- Visualizar indicadores comerciales.

---

# Usuarios

Administrador

- Configura el sistema.
- Importa archivos.
- Administra campañas.
- Consulta indicadores.

Asesor Comercial

- Consulta clientes.
- Atiende conversaciones.
- Envía mensajes manuales.
- Gestiona seguimientos.

Gerencia

- Consulta indicadores.
- Revisa resultados.
- Analiza campañas.

---

# Flujo Principal

1. Exportar clientes desde MyAsis.
2. Exportar ventas desde MyAsis.
3. Subir ambos archivos.
4. Automatize It procesa la información.
5. Se actualizan clientes y compras.
6. Se programan automatizaciones.
7. Se envían mensajes.
8. Se reciben respuestas.
9. El asesor continúa la conversación.

# Fuera del MVP

No incluye:

- Facturación.
- Inventario.
- Contabilidad.
- Gestión de vehículos.
- Compras.
- Proveedores.
- Nómina.
- Integración directa con la base de datos del ERP.
- Inteligencia Artificial.
- Aplicación móvil.

---

# Criterios de Éxito

El MVP será exitoso cuando permita:

- Importar información sin errores.
- Identificar clientes automáticamente.
- Programar campañas.
- Enviar mensajes.
- Registrar respuestas.
- Mostrar indicadores básicos.
