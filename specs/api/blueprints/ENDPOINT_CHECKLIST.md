# Endpoint Checklist

Antes de implementar cualquier endpoint verificar:

- [ ] Existe contrato OpenAPI
- [ ] Existe Schema
- [ ] Existe Request
- [ ] Existe Response
- [ ] Tiene ejemplos
- [ ] Tiene códigos HTTP correctos
- [ ] Tiene errores documentados
- [ ] Tiene autenticación
- [ ] Tiene autorización
- [ ] Está documentado en Swagger
- [ ] Tiene DTO
- [ ] Tiene Validación
- [ ] Tiene Test
- [ ] Tiene integración Frontend

Solo cuando todo esté completo el endpoint puede considerarse terminado.
