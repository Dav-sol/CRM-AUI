# Frontend Checklist

## Arquitectura

- [ ] El módulo frontend corresponde a una capacidad de negocio.
- [ ] La estructura es modular.
- [ ] No existe acoplamiento innecesario entre módulos.
- [ ] Las responsabilidades están claras.

## UX

- [ ] Flujo principal definido.
- [ ] Estado de carga.
- [ ] Estado vacío.
- [ ] Estado de error.
- [ ] Confirmaciones para acciones destructivas.
- [ ] Mensajes comprensibles para el usuario.
- [ ] Navegación consistente.

## Formularios

- [ ] Validación cliente.
- [ ] Validación servidor asumida como autoridad final.
- [ ] Errores asociados al campo correcto.
- [ ] Estados de envío.
- [ ] Prevención de acciones duplicadas.

## Seguridad y permisos

- [ ] La UI respeta permisos.
- [ ] La UI no se considera mecanismo de seguridad.
- [ ] Las restricciones reales se validan en backend.

## Responsive

- [ ] Desktop.
- [ ] Tablet.
- [ ] Mobile.

## Accesibilidad

- [ ] Navegación por teclado.
- [ ] Labels.
- [ ] Contraste adecuado.
- [ ] Estados comprensibles sin depender exclusivamente del color.

## Consistencia

- [ ] Componentes reutilizados cuando corresponda.
- [ ] Terminología consistente con el dominio.
- [ ] Fechas y números presentados consistentemente.
